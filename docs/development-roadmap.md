# Программа модернизации KYŪREIKA

Выбранные направления: 01–07 и 10. Интерфейс не расширяется.

| Направление | Критерий готовности |
|---|---|
| 01 Память | Проверяемая консолидация, сохранение происхождения знаний, тесты поиска и дубликатов |
| 02 Мышление | Несколько этапов рассуждения с сохранением промежуточных результатов и альтернатив |
| 03 Логика | Контрпримеры, проверка доказательств, отзыв зависимых выводов |
| 04 Внутренний мир | Версионированная модель личности, биография и согласованность поведения |
| 05 Самостоятельность | Очередь исследовательских задач, приоритеты, завершение и проверка результата |
| 06 Воображение | Изолированные сценарии, сравнение альтернатив без изменения фактов |
| 07 Самообучение | Измерение результатов, обратная связь, проверка улучшений |
| 10 Самосовершенствование | Анализ исходников, предложения патчей, изолированные тесты, проверка и откат |

## Порядок
Сначала воспроизводимые тесты существующего ядра, затем память и логика, многоступенчатое мышление, личность, исследовательская самостоятельность, сценарии, адаптация и контролируемое улучшение кода.

Фоновые функции включены по умолчанию при наличии необходимых настроек. Внешние действия и применение самостоятельно сгенерированных патчей требуют отдельного разрешения. Не считать гипотезы фактами или активность доказательством роста интеллекта.

Статус: план принят; выполнение и тестирование отдельных критериев ещё не подтверждены.
